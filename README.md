# NGワードパーティー

黄色と黒の注意テープ、紫のマスコットを使ったNGワードパーティーのWebアプリ試作です。

## 現在入っている機能
- 3〜10人で遊べる
- プレイヤー名と色を設定
- 複数ジャンル選択
- タップ後、5秒のカウントダウンでワード表示
- プレイヤーごとに重複しないワードを割り当て（選択ジャンル内のサンプル語から抽選）
- 忘れた人のワードを個別に確認
- 「ワードを隠す」「もう一度確認する」
- PWAの基本設定（ホーム画面追加・簡易オフラインキャッシュ）

## GitHubにアップロードする方法（iPhoneでも可）
1. GitHubで新しいリポジトリを作成します。例：`ngword-party`
2. このZIPを解凍します。
3. 解凍したフォルダ内のファイルをリポジトリにアップロードします。`index.html` はリポジトリの直下に置きます。
4. GitHubリポジトリの **Settings → Pages** を開き、Build and deployment を **Deploy from a branch**、Branch を `main`、フォルダを `/(root)` にして保存します。
5. 数分待つと、GitHub PagesのURLで試せます。
6. iPhoneではそのURLをSafariで開き、共有メニューから「ホーム画面に追加」を選べます。

## 重要：Google Playで公開する前に
これはWebアプリの試作で、AndroidのAPK/AABそのものではありません。Google Playで公開するには、Androidアプリとしてのパッケージ化・実機テスト・アプリ署名・ストア掲載情報が別途必要です。
また、広告（AdMob）、同意管理、プライバシーポリシー、年齢・コンテンツ設定、Google Playのデータ安全性申告はまだ実装していません。広告を組み込む場合は、Googleの現行ポリシーに沿って実装・テストしてください。
